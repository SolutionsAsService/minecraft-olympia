Install Olympia

Olympia is a Fabric mod for Minecraft 1.21.4. No release jar is published yet, so you build it. It is also in the Greek Pantheon mod pack in shadw-modding.

Words used here: a mod is an add-on for the game; a jar is the mod’s file; Fabric is the program that loads mods; an operator is a player allowed to use admin commands.

You need

  • Minecraft Java Edition 1.21.4 (not Bedrock)
  • Fabric Loader 0.16 or later, and Fabric API
  • Java 21 and Gradle 8 (the repository has no Gradle wrapper)

Build

git clone https://github.com/SolutionsAsService/minecraft-olympia
cd minecraft-olympia
gradle build
# the jar is in build/libs/olympia-0.1.0.jar

Copy the jar into your mods folder and start the game. The server log line Olympia loaded: 13 potions, 13 brewing recipes, 0 unknown effects skipped; 40 blocks, 12 gods, 5 creatures confirms the registration.

Commands

Commands
/olympia favorYour favor and stage with each god.
/olympia offer <god>Operators: offer the item in your hand to a god (the same code the altar runs).
/olympia setfavor <god> <n>Operators: set your favor with a god, for testing.
/olympia useOperators: use the held item exactly as a right-click does.
/olympia threadOperators: print what the held Thread of Ariadne says.

Status
